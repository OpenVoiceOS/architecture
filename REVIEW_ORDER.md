wave of pull requests is open and should be deleted when the wave lands.

Every PR in the wave carries the same body template: **What / Why (with the
defect cited) / Semantic change? / Owner decision needed? / Depends on**.

Three categories, in merge order:

- **editorial** — zero semantic change, rubber-stampable;
- **normative fix** — each repairs a named contradiction or gap, with the clash
  cited in the body;
- **[proposal]** — adds requirements beyond repairing a defect. Titled
  `[proposal]`. Each is stacked on the normative-fix PR for the same file, so
  its diff shows the addition alone.

No PR in this wave touches `CHANGELOG.md` and none bumps a spec `Version`
header. The specs are unreleased and are all one version.
